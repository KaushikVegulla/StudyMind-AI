Stacks
A stack is a linear data structure that follows the Last In First Out principle, known as LIFO. The element inserted last is the first one removed. The push operation adds an element to the top of the stack. The pop operation removes and returns the top element. The peek operation reads the top element without removing it. A stack underflow happens when pop is called on an empty stack, and overflow happens when a fixed size stack is full. Stacks are used in function call management, where each call is pushed as a frame, and in undo mechanisms in text editors. Expression evaluation uses a stack to convert infix expressions to postfix form. The time complexity of push and pop operations is constant, written as O(1).

Queues
A queue is a linear data structure that follows the First In First Out principle, known as FIFO. Elements are added at the rear and removed from the front. The enqueue operation inserts an element at the rear of the queue. The dequeue operation removes the element at the front. A circular queue connects the rear back to the front so that empty spaces at the beginning are reused. A priority queue removes the element with the highest priority first, rather than the oldest element. Queues are used in breadth first search of graphs, in printer job scheduling, and in handling requests on a single shared resource. The front pointer tracks the element to be removed next, and the rear pointer tracks the last inserted element.

Binary Search Trees
A binary search tree, or BST, is a node based binary tree data structure with a special ordering property. For every node, all keys in its left subtree are smaller than the node's key, and all keys in its right subtree are greater. This ordering makes searching fast: at each node, half of the remaining tree can be discarded. An inorder traversal of a binary search tree visits the keys in sorted ascending order. The height of the tree decides the cost of operations; a balanced tree gives logarithmic time, while a skewed tree degenerates into a linked list with linear time. Insertion begins at the root and moves down, comparing keys, until an empty spot is found for the new leaf. Deletion has three cases: a leaf node is simply removed, a node with one child is replaced by that child, and a node with two children is replaced by its inorder successor.
